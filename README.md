# GTA VI Detona BR

Portal brasileiro de fãs (não oficial) sobre GTA VI: notícias diárias, cheats, dicas, easter eggs, descobertas e rumores sobre GTA VII.

- **Site:** publicado via GitHub Pages a partir da branch `main` (Jekyll nativo, sem build próprio).
- **Para IAs / automação:** leia [`AGENTS.md`](AGENTS.md) e [`docs/AUTOMACAO.md`](docs/AUTOMACAO.md).
- **Monetização:** [`docs/MONETIZACAO.md`](docs/MONETIZACAO.md).
- **Novo post:** copie [`docs/TEMPLATE-POST.md`](docs/TEMPLATE-POST.md) para `_posts/AAAA-MM-DD-slug.md`.
- **Validar posts:** `powershell -File scripts/validar-posts.ps1`
- **Rodar localmente (opcional):** `bundle install && bundle exec jekyll serve` e abra `http://localhost:4000/gtavi/`.

Grand Theft Auto e marcas relacionadas pertencem à Rockstar Games / Take-Two Interactive. Este projeto não tem vínculo com elas.
