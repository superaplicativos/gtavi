{% comment %} Área para código de OUTRA rede (Media.net, Rubicon, etc.). Como usar: em _config.yml troque ads.provider para "custom" e cole aqui o código do banner. A variável include.slot diz qual posição está sendo renderizada (top, infeed, article, sidebar, footer) - use um if por slot se quiser banners diferentes em cada posição. As redes já cadastradas ficam em arquivos próprios na mesma pasta: - ads/adsterra.html (banners Adsterra por slot) - ads/socialbar.html (Social Bar Adsterra, global) Formatos suportados aqui: banner/display. Popunder e Direct Link não. {% endcomment %}
